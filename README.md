# TicketFlow Service Desk

Корпоративна Front End система за управление на служебни тикети и вътрешна комуникация.

## Технологии

- HTML5
- CSS3
- TypeScript
- React
- Vite

Проектът не използва backend, база данни, Firebase или API заявки. Работните данни се зареждат локално от TypeScript файл.

## Стартиране

```bash
npm install
npm start
```

След стартиране Vite отваря приложението на локален адрес, обичайно `http://127.0.0.1:5173`.

## Build

```bash
npm run build
```

Vite е конфигуриран с `base: "./"`, така че генерираният `dist/index.html` може да се отвори директно в браузър.

## Вход

- Потребител: `admin`
- Парола: `admin123`

Натискането на бутона „Вход“ зарежда системата.
